Conversion DA

  • Version Number: 2.0.4
  • Revision Date: 1994
  • Byte Size: 83K
  • License: Shareware
  • Rick Johnson wrote this back in '94 for his own use, and added a few (basically all) other units of measurement to make it useful for anyone. It will convert any form of measurement you can imagine to any other like measurement. It converts quickly, with no fancy graphics, and takes up a minimum amount of space. I've played with many other converters written for the Mac and personally think this one is the best of them all.

Disk Wizard

  • Version Number: 2.0
  • Revision Date: March 14, 1995
  • Byte Size: 291K
  • License: Shareware
  • Homepage
  • Disk Wizard is an advanced disk cataloging program. It is made up of two components: a system extension and an application. Once it is installed, Disk Wizard automatically catalogs the contents of your volumes (hard disks, floppies, CDs, SyQuests, whatever). Thus, Disk Wizard's catalog is always up-to-date, without your needing to do any scanning chores. At any time, you can launch the Disk Wizard application. In seconds, it will answer questions such as "Where did I put file X?" or "On what floppy can I store this 300K file?". It will let you copy files from your backup media simply by dragging them from Disk Wizard to the Finder (if you have System 7.5). It will also expand StuffIt archives on the fly (if you have Aladdin's StuffIt Engine). It will look for duplicate files on your disks. Disk Wizard is now accelerated for Power Macintosh.
  • MacShare comments: If you have a lot of software stored on removable media, then this is for you. I highly recommend this application.

MacBinary II+

  • Version Number: 1.0.2
  • Revision Date:July 26, 1996
  • Byte Size: 24K
  • License: Freeware
  • MacBinary II+ is a System 7 drag & drop converter for MacBinary files. It has no User Interface, simply drop a MacBinary file on it and it will be decoded, drop any other file or folder on it and it will be encoded. MacBinary II+ should be fully compatible with all current MacBinary encoders/decoders, and extends the format to include folder hierarchies (although no other decoder will be able to decode folder hierarchy MacBinary files created by MacBinary II+).
  • MacShare comments: This program, in combination with Stuffit Expander and UUCD should be all you'll ever need to decipher any coded application you download off of the internet.

  • Revision Date: May 30,1995
  • Byte Size: 531K
  • License: Freeware
  • SoundEffects is a powerful sound editor. Not only can SoundEffects change sounds in many ways through its variety of effects, but it can also handle multi-channel sounds, sampled at any rate up to 64kHz and with any sample size between 1 and 32 bits. Virtual

  • Version Number: 2.0
  • Revision Date: May 28, 1998
  • Byte Size: 340K
  • License: Shareware
  • If you're familiar with X-Windows workstations, you have probably used one virtual window manager or other. Virtual is one of those, for the Mac. It presents you with multiple 'virtual screens' where you can place your windows, so you don't have a clutter of them on your real screen. You can switch virtual screens with a key combination, or by choosing that screen in the Virtual window. You can drag windows around to move them to other screens, and so on.
  • MacShare comments: This has become one of my MOST used utilities. You can configure it to contain as many different desktops as you need!! If you like to have tons of windows open like I do, this is for YOU.

ZipIt

  • Version Number: 1.3.8
  • Revision Date: September 7, 1997
  • Byte Size: 626K
  • License: Shareware
  • Homepage
  • ZipIt is a full-featured Macintosh archival program. It is fully compatible with PKWare, Info-Zip, and other zip compression products. ZipIt includes a complete Macintosh interface, and boasts Mac-specific features such as AppleEvent support and Macintosh Drag and Drop, as well as general features such as encryption (in the United States and Canada) and segmenting.
  • MacShare comments: If you have friends who live in the DOS world, this is an application you can use. .Zip is their version of .Sit for the Mac. It's also useful for those rare occasions when Stuffit Expander can't "unzip" a file. I had that happen once, and this program was all that saved that particular file from the trash.
