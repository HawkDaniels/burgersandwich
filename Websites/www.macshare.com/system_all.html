CacheSaver

  • Version Number: 1.0.2
  • Revision Date: August 18, 1997
  • Byte Size: 180 K
  • License: Shareware
  • You've probably found that increasing the size of the disk cache in the Memory control panel can improve the performance of many applications. The disk cache speeds things up by keeping the contents of files in RAM, rather than immediately reading or writing from the hard disk. The problem is that when you save information to a large disk cache, the data may end up staying in the cache for a while before it gets written to your hard disk. If your Mac crashes before the cache gets saved, your data may be lost. CacheSaver addresses this problem by periodically saving, or "flushing," the disk cache, thus minimizing data-loss.
