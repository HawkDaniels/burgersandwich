You will be downloading directly from other pages and FTP sites, and as such, you should be sure to check ANY software you download for viruses. I suggest you purchase Norton AntiVirus for Mac, but a high quality freeware application exists and it's called Disinfectant.

For more information regarding the Internet you might want to read the online edition of Adam Engst's book: Internet Starter Kit for Macintosh.

MacShare recommends:

AOL's Instant Messenger UPDATED!

  • Version Number: 4.0.1039
  • Revision Date: May 29, 2000
  • Byte Size: 2716K
  • License: Freeware
  • Homepage
  • With AOL Instant Messenger you can see who's currently online. Your personal Buddy List shows you which of your business associates, friends, and family are online right now! And, you can send a Quick & Private Instant Message. You can use AOL Instant Messenger with any Internet connection; easily transfer your personal Buddy List and preferences to different computers. You can send styled, and colored text, as well as clickable Web links. You can customize AOL Instant Messenger with your favorite sounds. You can enjoy a safe and private online environment. The Neighborhood Watchª program and privacy controls give you the power to "warn" users that send you unwanted messages and to control who is able to 'see' you online.
  • MacShare comments: Fantastic way to stay in touch with friends online. The only caveat is that BOTH of you need to have this application for it to work. Not a problem. Your friend can even be a (gasp) Windows user. I talk to my very dear friend in Japan with this. A great way to save on lonnnnnggggg distance.

Better Telnet UPDATED!

  • Version Number: 2.0fc1
  • Revision Date: May 1, 2000
  • Byte Size: 370K
  • License: Freeware
  • BetterTelnet is a significantly enhanced version of NCSA Telnet 2.7b4. It fixes many bugs and has a redesigned interface that is not only easier to use and configure than NCSA Telnet, but still has as much as if not more configuration flexibility compared to NCSA Telnet. All configuration options from NCSA Telnet are still in BetterTelnet. Better Telnet allows you access to the UNIX systems that are likely what you tap into when you sign onto your server. This client software is necessary if you wish to communicate with certain aspects of an Internet provider.
  • MacShare comments: Mostly, this application runs in the background when Netscape needs it to link to other servers. Needed for the avid web-surfer and those of you who are forced to talk to the Unix machine at your server. Highly recommended.

Big Brother

  • Version Number: 1.2
  • Revision Date: April 1, 1997
  • Byte Size: 750K
  • License: Shareware
  • Homepage
  • Big Brother is a hyperlink validation tool. Feed it your HTML source and sit back while it checks it. It will notify you when a remote document is no longer available and will display its new address whenever possible. It can also check internal links offline.
  • MacShare comments: This works much more quickly that I imagined it would. Very useful if you have a large website, (small sites will like it too).

Eudora eMail UPDATED!

  • Version Number: 5.0.1
  • Revision Date: November, 2000
  • Byte Size: 3387K
  • License: Freeware
  • Homepage
  • QUALCOMM's new Eudora 5.01 provides users with an industrial-strength email program for free when they use it in Sponsored mode.
  • MacShare comments: This is a great application. It is probably the best email client available in shareware, even over Netscape's add-on. It has the ability to skip past "headers" when opening your newest piece of mail. You only need one E-mail program, and this is it. Paid mode is best, as it gets rid of the advertisement. This replaces all versions of Eudora, Pro and Light.

Fetch

  • Version Number: 3.0.3
  • Revision Date: March 12, 1997
  • Byte Size: 966K
  • License: Shareware
  • Fetch 3.0 includes Multiple connections, Bookmark lists, Drag and Drop, AppleScript support, Internet Config 1.1 support, Support for SOCKS, S/Key, simple proxy servers, passive-mode transfers, and a user-settable TCP port range, Native Open Transport code, Info-Mac and UMich mirror support, Automatic disconnect and reconnect, Search and Set Permissions commands, Persistent directory list caching, Graphical progress indicator, and Numerous new preferences.
  • MacShare comments: Fetch is my favorite FTP Client. I use it to update my website every day. It's simple to use. With the newest version, you can continue unfinished downloads from previous sessions. Highly recommended.

HTML Markup

  • Version Number: 3.0.1
  • Revision Date: August 8, 1999
  • Byte Size: 1097K
  • License: Shareware
  • Homepage
  • HTML Markup is an "HTML processor". Unlike editors, it converts existing files into web pages. Unlike converters, it allows you to customize how the files look.
  • MacShare comments: If you want to post an article on your website, this is the quickest way to get it done. I love this converter.

Ircle

  • Version Number: 3.0
  • Revision Date: May 1, 2000
  • Byte Size: 1271K
  • License: Shareware
  • Official Homepage
  • Ircle is a client aplication which allows you access to the very popular world of IRC (Internet Relay Chat), which is a multi-user online chatting system. It allows users to talk to other users all around the world via the Internet. This is done by connecting a client program (such as this one) to a server.
  • MacShare comments: I've tried other IRC clients, but this one is the most stable. It isn't as easy to use, and is not especially user friendly. But, it works well, and there is extensive help available.

Microsoft Explorer NEW TO MACSHARE!

  • Version Number: 5.0
  • Revision Date: May 1, 2000
  • Byte Size: 11.5 Meg
  • License: Freeware
  • Built for speed and compliant with Internet standards, IE 5 strikes a balance between users' needs and developers' desires. IE 5 is the first browser to correctly and fully implement the two-year-old HTML 4 and CSS-1 Web standards. But IE 5 still has a ways to go; it offers only partial support for the XML, CSS-2, and DOM-1 standards, which will usher in the next wave of Web innovation.
  • MacShare comments: Microsofts answer to Netscape, usually under scrutiny by the U.S. Government, with accusations of illegal monopolies threatening to break up Bill Gates company, much the way that Ma-Bell was segmented long ago. Personally, I never intend to use this, except on silly sites where Netscape fails to work, usually at the hands of Microsoft fans, or inept programmers. (Is that a BIT harsh?) I include it here, only because the current MacOS comes loaded with this application, and thought you might like to keep it updated, even if you never use it.

NetScape Communicator UPDATED!

  • Version Number: 4.7.4
  • Revision Date: July 19, 2000
  • Byte Size: 13 Meg
  • License: Freeware
  • A Web-browser with very powerful features, constantly undergoing updates to make it even better.
  • MacShare comments: If you aren't using NetScape for your Web-browser, you need to download one of these. There is no better browser available. You have several options from the Standalone Web Browser known as Navigator, all the way up the the professional level Communicator software package. You can even download the preview release of version 6.0, which should embarrass Microsoft's browser (see above)

Newswatcher

  • Version Number: 2.2.2
  • Revision Date: March 2, 1998
  • Byte Size: 665K
  • License: Freeware
  • Newswatcher is a Usenet news reader.
  • MacShare comments: You can read usenet news with NetScape, but this application is better at it. It allows you to keep seperate files of Usenet subjects, checks for new Usenet groups, and automatically grabs all parts of larger files and decodes them after downloading, saving you the frustration of getting each section seperately. Very convenient and easy to use. Highly recommended.

Sound Machine

  • Version Number: 2.7.1
  • Revision Date: April 2, 1997
  • Byte Size: 386K
  • License: Freeware
  • Homepage
  • Sound Machine is the Internet standard for playing back sound clips you will find in your web surfing travels. It can decode .au files very easily. Useful with an interesting user interface. Netscape loves to file this under "helper applications" in the preferences file.
