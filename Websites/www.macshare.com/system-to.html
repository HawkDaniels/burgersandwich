MacShare recommends:

Amico

  • Version Number: 2.1.1
  • Revision Date: October 8, 1998
  • Byte Size: 100K
  • License: Shareware
  • Amico is an acronymn for "Apple Menu Items Custom Order". It simply lets you change the order of the items that appear in the apple menu, in a very easy way. In addition, you can insert divider lines to group related items together.
  • MacShare comments: This is a small, and quick loading extension that really helps organize an overloaded Apple-Menu. If you aren't using OtherMenu (see below), this is a very useful alternative. Works well with OS 9.

ApplWindows

  • Version Number: 2.0.2
  • Revision Date: September 18,1994
  • Byte Size: 50K
  • License: Freeware
  • ApplWindows is a Control Panel that provides a variety of app- and window-switching features to the Finder.
  • MacShare comments: After getting used to this, I find I cannot go back. ApplWindows is an older item, but works well with the newer MacOS. A very convenient app switcher, allowing you to access it from any side of the screen. Highly recommended if you run several applications or have several windows open at once. MacOS 9.0.4 compatible.

ATM Light NEW!!

  • Version Number: 4.6
  • Revision Date: July 9, 2000
  • Byte Size: 2.5 meg
  • License: Freeware
  • Adobe® Type Manager® (ATM®) Light is a system software component that automatically generates high-quality screen font bitmaps from PostScript® Type 1 or OpenType outline font data. With ATM, you can scale your fonts without the characters appearing jagged, and you can also enable "font smoothing," which further improves the appearance of your fonts on-screen by using your computer monitor's color palette to intelligently improve the rendering of characters. ATM Light also allows you to print PostScript fonts on non-PostScript printers, and can be used to create custom instances of multiple master fonts.
  • MacShare comments: A standard item every Macintosh should have loaded at all times. Now that the "light" version is freeware, there's no excuse not to have this in your "must-have" llist of software. Requires System 8.1 or higher.

GlidelUPDATED!!

  • Version Number: 5.0.1
  • Revision Date: July 9, 2000
  • Byte Size: 217K
  • License: Shareware
  • Glidel is a system extension that extends the Finder's drag-and-drop abilities. You can select any icon currently visible, either on your Desktop or in an open folder, and drag it to:
    • The Open, Print, Get Info, Sharing..., Duplicate, Make Alias, Put Away, and Show Original options on the File menu;
    • Any application or folder in the Apple menu, including those accessible via a third-party hierarchical menu utility such as BeHierarchic, NowMenus, HAM, or OtherMenus;
    • Any currently running application, via the Application menu on the right-hand side of the menu bar.
  • MacShare comments: Very convenient. Add this with ApplWindows for a great addition to the Mac GUI. Works just fine with MacOS 9.0.4

OtherMenu

  • Version Number: 2.0.3
  • Revision Date: November 1, 1999
  • Byte Size: 340K
  • License: Shareware
  • OtherMenu creates a system-wide hierarchical menu somewhat like the Apple menu. Besides opening applications and documents, it runs 28 little utilities called externals. In a directory dialog (Open/Save dialog), you can use the menu to select a file or folder. Compatible with System 7 through 9.0.4. Some PowerPC code.
  • MacShare comments: One of the best alternatives to the Apple Menu hierarchical setup that comes with the MacOS. This offers many useful extras. It will also speed up slower Macs if you use it instead of the Apple Menu for navigation.

Pictify

  • Version Number: 1.5
  • Revision Date: April 13, 1994
  • Byte Size: 44K
  • License: Freeware
  • PICTify is a control panel that provides you with screen capturing capabilities. You may capture the entire screen, a selection that you define, the frontmost window, or a pulled-down menu (including popup menus) to a file or to the clipboard. If you choose to save the snapshot to a file, you have the option of saving it to a SimpleText PICT file or to a ResEdit file which will contain a 'PICT' resource and a couple of other resources which define the dimensions of the PICT.
  • MacShare comments: My control panel of choice for capturing cool AfterDark images for my personal graphic library.

PopUpCD

  • Version Number: 1.5.2
  • Revision Date: November 3, 1999
  • Byte Size: 181K
  • License: Shareware
  • PopupCD is a resident audio CD player with full-function popup remote control, track name popup menu, definable keyboard shortcuts, and save-to-disk features for convenient control of your CDs.
  • MacShare comments: From the makers of CalcWorks, comes a little control panel that is more convenient to use than Apple's own CD Audio Player. If you like to listen to audio CD's, I highly recommend you download this item and see if you don't think this is the best way to control your music.

Sounds4Fun

  • Version Number: 1.0
  • Revision Date: May 3, 1998
  • Byte Size: 227K
  • License: Shareware
  • Homepage
  • Like Apple's sound settings in the Appearance control panel, Sounds4Fun allows you to change the sound your Mac utters as it goes through various tasks. Unlike Apple, Sounds4Fun also allows you assign sounds to many other distinct events. Events can be assigned a sound by using the Control Panel.
  • MacShare comments: This even allows you to have random sounds assigned to different events. I've used it's predecessor, SndControl forever, and had never found a better sound manager, until now. This one takes up where SndControl left off. Fully compatible with MacOS 9. It's still one of my favorite system enhancements.

Symbionts

  • Version Number: 2.8.5
  • Revision Date: April 6, 2000
  • Byte Size: 132K
  • License: Shareware
  • Symbionts is an extension manager. It comes in two parts, an extension and a control panel. The extension monitors the startup process. Symbionts displays the name and number of bytes of memory each system extension allocates from the system heap. The name and number appear beneath the extension's icon, and since the name is usually truncated, Symbionts also displays it in the menu bar. Symbionts even shows the icons for those extensions that don't normally reveal themselves. The Control panel sets the preferences for the Symbionts extension. It also allows the review of the information collected by the Symbionts extension. Additionally, the control panel is used to manage the loading of system extensions without having to dig around in the System folder. Extension can be enabled and disabled simply by double-clicking on the extension icon and name.
  • MacShare comments: Back when I used a shareware version of an extension manager, this was my favorite pick. Since those days, I've started using ConflictCatcher(TM), which is a commercial product. But, if you need to stick with Shareware, this is your best bet, in my opinion. I WOULD take the time to read the instructions that come with it though. I crashed my computer a few times until I took the time to read, as there are some things you MUST know before using this item.

TypeIt4Me

  • Version Number: 4.8.1
  • Revision Date: June 6, 1999
  • Byte Size: 530K
  • License: Shareware
  • Homepage
  • What does TypeIt4Me do? Anytime you can enter text in your Mac by typing it at the keyboard, TypeIt4Me can do it for you - faster and more accurately. Once you define a number of entries, you can let the Mac do the typing for you. The entries can be as short as a single word or as long as several paragraphs. Each entry bears a short, easily remembered name assigned by you, known as the abbreviation. To trigger off the automatic typing of the text of an entry you can either: type the entry's abbreviation or select the abbreviation from TypeIt4Me's pop up menu. For example, instead of typing my name in full, I simply type re and TypeIt4Me comes up with Riccardo Ettore.
  • MacShare comments: A great control panel that does one thing the description above doesn't mention, it will allow you to paste today's date into any document in several formats. I cannot live without this great helper, which saves me from a lot of extra typing.
