Website Tutorial (Windows)

Part 1: Setup

Step 1. Create a Cloudflare account.

Step 2. Create a Github account and install Github Desktop.

Step 3. Install git.

Step 4. Install Visual Studio Code.

Part 2: Domain Registration

Step 1. Buy a domain. (I used GoDaddy, but Cloudflare can also provide a domain)

Step 2. If you register your domain through a service other than Cloudflare, you will need to manually update your name servers and DNS settings.

Part 3: Deploying the Website

Step 1. Create a new repository on GitHub.

Step 2. Connect to the repository using Github Desktop.

Step 3. Create a new file named `index.html` in the repository.

Step 4. Using a tutorial or another website as reference, develop your homepage.

Step 5. Once you have a basic homepage complete, commit your changes and push them to GitHub.

Step 6. On the Cloudflare dashboard, create an application and continue with GitHub.

Step 7. Select the repository for your webpage.

Step 8. As you continue to develop your website, commits pushed to GitHub should deploy automatically.
